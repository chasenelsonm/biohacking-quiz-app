──────────────────────────────────────── 1. Testing the Application

A. Start the Application with Docker Compose
    • Ensure Docker is installed and running on your system.
    • Open a terminal and navigate to the project directory:
        cd C:\Users\chase\Desktop\localstack\biohacking-quiz-application\quiz-api-app
    • Start the app with Docker Compose:
        docker-compose up
    • Verify it’s running by checking the logs or accessing the API at http://localhost:3000.

B. Test All Endpoints

• GET /api/quizzes
    Use Postman or curl:
        curl http://localhost:3000/api/quizzes
    Verify that the quiz data appears.

• POST /api/quizzes
    From Postman, create a new quiz by setting the method to POST, URL to http://localhost:3000/api/quizzes, header Content-Type: application/json, and use a sample JSON (or the multi-quiz JSON if your backend supports arrays).
    Verify the new quiz is created.

• PUT /api/quizzes/{id}
    Update an existing quiz by sending a proper JSON payload to the PUT endpoint. Verify the updated data returns when using GET.

• DELETE /api/quizzes/{id}
    Send a DELETE request and then use GET to ensure the quiz has been removed.

C. Manually Test in VS Code
If needed, use the integrated Terminal in VS Code to execute docker-compose up and use Postman within VS Code to verify endpoints quickly.
